## 📌 精选项目

### [Multi-Agent-Exp](https://github.com/hncjxywyh/Multi-Agent-Exp)

> 基于 LangGraph 的多智能体智能数据查询系统。该仓库当前为 Fork，我在此基础上进行了功能扩展和实验，项目页面会持续补充个人改动说明。

- 使用主智能体协调 SQL 查询、数据分析和联网搜索子智能体。
- 通过条件路由覆盖简单问答、SQL、分析、联网搜索和联合对比等场景。
- 使用 Reflection 在 SQL 执行失败时反馈错误信息并重试生成。
- 使用短期会话压缩和长期用户偏好保存支持跨轮次对话。

### 百科AI

教育类 AI 平台实习项目，展示已获授权的功能信息：

- 计算类题目使用 SymPy 进行确定性验算，减少模型在数值判断上的误判。
- 使用 Fact Store 保存多轮对话中的关键条件和用户修正。
- 采用 Query Rewrite、BM25、向量召回和 Cross-Encoder 重排构建 RAG 链路。

### Mat-voice

多模态工具平台实习项目，展示已获授权的功能信息：

- 编排腾讯云 ASR 与百度翻译 / OCR 服务，统一语言编码和响应结构。
- 使用独立线程池、有界队列和超时控制隔离耗时任务。
- 通过 RabbitMQ 异步记录调用事件，使用 MySQL 保存时长、状态和失败原因。
